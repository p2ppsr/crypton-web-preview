# Crypton Web preview

Open https://p2ppsr.github.io/crypton-web-preview/ inside Metanet Explorer.

This repository contains only the compiled iPhone/iPad test website. The source is maintained separately. Recipient search requires an ME build with working identity discovery; older ME builds may return no matches. The web app does not require TestFlight.

Send creates an encrypted QR to share. It does not submit a MessageBox payment.
